Game Vault Setup

Firebase is already configured! This setup is only needed if you want to use a different Firebase project.

1. Create a Firebase Project

Go to firebase.google.com and create a new project

2. Add a Web App

Click the </> icon (Add app) -> Choose "Web" -> Register

3. Enable Authentication

In Firebase Console -> Authentication -> Get Started -> Email/Password -> Enable -> Save

4. Create Firestore Database

Firestore Database -> Create database -> Start in test mode -> Enable

5. Paste Your Firebase Config

Easy way: Copy the entire config block from Firebase and paste it here.

6. Set Firestore Rules

Copy and paste these rules into Firebase Console -> Firestore -> Rules:

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /users/{uid} { allow read: if request.auth != null; allow write: if request.auth != null && request.auth.uid == uid; } match /users/{uid}/{document=**} { allow read: if request.auth != null; allow write: if request.auth != null && request.auth.uid == uid; } match /posts/{postId} { allow read: if request.auth != null; allow create: if request.auth != null; allow update: if request.auth != null && request.auth.uid == resource.data.userId; allow delete: if request.auth != null && request.auth.uid == resource.data.userId; } } }

IMPORTANT: Click PUBLISH after pasting the rules.
