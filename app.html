Admin Setup

Update Firebase configuration.

1. Create a Firebase Project

Go to firebase.google.com and create a new project

2. Add a Web App

Click the / icon (Add app) -> Choose "Web" -> Register

3. Enable Authentication

In Firebase Console -> Authentication -> Get Started -> Email/Password -> Enable -> Save

4. Create Firestore Database

Firestore Database -> Create database -> Start in test mode -> Enable

5. Paste Your Firebase Config

Easy way: Copy the entire config block from Firebase and paste it here.

6. Set Firestore Rules

IMPORTANT: Copy and paste these rules into your Firestore Rules panel.

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { // Users can read/write their own profile match /users/{uid} { allow read: if request.auth != null; allow write: if request.auth != null && request.auth.uid == uid; } // Users can read/write their own subcollections match /users/{uid}/{document=**} { allow read: if request.auth != null; allow write: if request.auth != null && request.auth.uid == uid; } // Friend requests match /users/{uid}/requests/{requestId} { allow read: if request.auth != null && request.auth.uid == uid; allow create: if request.auth != null && request.auth.uid != uid; allow delete: if request.auth != null && request.auth.uid == uid; allow update: if false; } // Friends list match /users/{uid}/friends/{friendId} { allow read: if request.auth != null && request.auth.uid == uid; allow create: if request.auth != null && request.auth.uid == uid; allow delete: if request.auth != null && request.auth.uid == uid; allow update: if false; } // Game ratings & reviews – anyone can read, only owner can write match /users/{uid}/gameRatings/{gameId} { allow read: if request.auth != null; allow write: if request.auth != null && request.auth.uid == uid; } // Posts match /posts/{postId} { allow read: if request.auth != null; allow create: if request.auth != null; allow update: if request.auth != null && ( request.auth.uid == resource.data.userId || request.resource.data.diff(resource.data).affectedKeys().hasOnly([ 'score', 'upvotes', 'downvotes', 'chatMessages', 'chatCount' ]) ); allow delete: if request.auth != null && request.auth.uid == resource.data.userId; } // Post votes match /posts/{postId}/votes/{userId} { allow read: if request.auth != null; allow write: if request.auth != null && request.auth.uid == userId; } } }

✅ Allows friend requests, real‑time chat, ratings, reviews, and post interactions.

For community ratings: Create a composite index on collection gameRatings with fields gameId (asc) and rating (desc).
