Game Vault Setup

This app needs a free Firebase backend for login, friends, and save sharing. Follow these steps:

1. Create a Firebase Project

Go to firebase.google.com and create a new project named "game-vault"

2. Add a Web App

Click the </> icon (Add app) -> Choose "Web" -> Name it "Game Vault" -> Register

3. Copy Your Config Values

From the Firebase SDK snippet, copy each value into the fields below:

4. Set Security Rules (Important!)

In Firebase Console -> Firestore Database -> Rules, paste:

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /users/{uid} { allow read: if request.auth != null; allow write: if request.auth != null && request.auth.uid == uid; } match /users/{uid}/completions/{gameId} { allow read: if request.auth != null; allow write: if request.auth != null && request.auth.uid == uid; } match /users/{uid}/saves/{gameId}/files/{fileId} { allow read: if request.auth != null; allow write: if request.auth != null && request.auth.uid == uid; } match /users/{uid}/friends/{friendId} { allow read, write: if request.auth != null && request.auth.uid == uid; } match /users/{uid}/requests/{requestId} { allow read, write: if request.auth != null && request.auth.uid == uid; } } }

Then go to Storage -> Rules and paste:

rules_version = '2'; service firebase.storage { match /b/{bucket}/o { match /saves/{userId}/{allPaths=**} { allow read: if request.auth != null; allow write: if request.auth != null && request.auth.uid == userId; } } }
